# Walmart Sales KPI Dashboard

## Project Overview
This project analyzes Walmart sales performance using Power BI.  
The dashboard provides insights into sales trends, store performance, holiday impact, and economic factors affecting weekly sales.

---

## Tools Used
- Excel
- Power BI
- SQL (for KPI analysis practice)

---

## Dataset Features
- Store-wise sales data
- Weekly sales trends
- Holiday impact
- Fuel price analysis
- Unemployment analysis
- Temperature data

---

## Key Insights
- Holiday weeks generate higher average sales than regular weeks.
- Sales fluctuate seasonally across different months.
- Higher unemployment levels appear associated with weaker sales trends.
- Some stores contribute disproportionately to total revenue.
- Fuel prices show limited impact on weekly sales performance.

---

## Dashboard Features
- KPI Cards
- Interactive Slicers
- Monthly Sales Trend Analysis
- Store Performance Comparison
- Economic Impact Analysis
- Interactive Dashboard Design
